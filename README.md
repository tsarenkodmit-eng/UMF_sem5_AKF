## Запуск

Требуются Python 3, NumPy и Matplotlib. Из корня репозитория:

    pip install -r requirements.txt
    python task1_wave.py --output-dir results

Скрипт сохраняет PNG/SVG-графики, CSV-профиль с абсолютной погрешностью и текстовую диагностику в каталоге results/.
