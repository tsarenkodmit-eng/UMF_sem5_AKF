# Уравнения математической физики: задания 1–4

- **[Отруки](Отруки)** — подробные аналитические выкладки и простые рисунки, без расчётных схем и численных результатов.
- **[Численные решения](Численные_решения)** — математические формулы вычислений, условия остановки, результаты и крупные цветные двумерные графики.
- **[Полное решение](Полное_решение)** — обе части каждого задания в одном PDF.
- **[Код](Код)** — четыре численные программы.

В задании 3 требуется МКР. В аналитической части выведена краевая задача для перемещений, а не заявлена несуществующая в работе явная формула. Найденные узловые перемещения, их восстановление между узлами и профили приведены в численной части.

В задании 4 отдельно выполнены три подпункта: канонический вид (4.1), краевая задача (4.2), граничное интегральное уравнение (4.3). Для матрицы в 4.1 явно указано прочтение её десятичной записи как округления дробной матрицы.
