# УМФ — задача 1

В репозитории реализована только задача 1: распространение волны сжатия от сферической полости в однородном изотропном линейно-упругом пространстве.

- task1_solution.md — подробный вывод от определений до уравнения Навье—Ламе, схемы МКР второго порядка и аналитического решения через задачу Коши для ОДУ.
- task1_wave.py — воспроизводимый расчёт и построение графика.

Запуск из корня репозитория:

    python task1_wave.py --output-dir results

Скрипт создаёт в results/ график PNG/SVG, профиль CSV и диагностические параметры. Остальные задачи из домашнего задания пока не реализовывались.
