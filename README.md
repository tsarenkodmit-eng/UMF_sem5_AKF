# Уравнения математической физики: задания 1–4

- **[Отруки](Отруки)** — аналитические решения, уравнения и схемы условий, без графиков и численных методов. В рамках выделены только итоговые ответы.
- **[Численные решения](Численные_решения)** — формулы вычислений, условия остановки, результаты, аналитические и численные кривые на крупных цветных 2D-графиках. Увеличения показывают фронт и ошибку у полости (1), скачок (2), первые узлы у заделки (3), восстановленную производную у угла (4).
- **[Полное решение](Полное_решение)** — обе части каждого задания в одном PDF.
- **[Код](Код)** — четыре численные программы.

В задании 3 требуется МКР. В аналитической части последовательно выведена краевая задача для перемещений. Найденные узловые перемещения, их восстановление между узлами и профили приведены в численной части.

В задании 4 отдельно выполнены три подпункта: канонический вид (4.1), краевая задача (4.2), граничное интегральное уравнение (4.3). Для матрицы в 4.1 явно указано прочтение её десятичной записи как округления дробной матрицы.

В папке [Подробный разбор](Подробный_разбор) два файла:

- [Полное решение заданий 1–4](Подробный_разбор/Задания_1-4_подробно.pdf) — аналитические выводы, численные методы и графики.
- [Аналитическое решение заданий 1–4](Подробный_разбор/Задания_1-4_аналитически.pdf) — выводы и ответы без численных методов и графиков.
