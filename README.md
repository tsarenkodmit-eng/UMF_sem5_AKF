## Результат

Для задания заданы $E=5.4\cdot10^9\ \mathrm{Па}$, $\mu=2.0\cdot10^9\ \mathrm{Па}$, $\rho=1800\ \mathrm{кг/м^3}$, $R=1\ \mathrm{м}$, $P_0=10^8\ \mathrm{Па}$, $h=0.01R$ и $\tau=h/C_p$.

$$
\rho u_{tt}=(\lambda+2\mu)\left(u_{rr}+\frac2r u_r-\frac{2}{r^2}u\right),\qquad r\ge R.
$$

$$
\sigma_{rr}(R,t)=(\lambda+2\mu)u_r(R,t)+\frac{2\lambda}{R}u(R,t)=-P_0H(t).
$$

| Контрольный показатель | Значение |
|---|---:|
| Скорость продольной волны $C_p$ | $2194.26863\ \mathrm{м/с}$ |
| Шаг времени $\tau$ | $4.55732715\cdot10^{-6}\ \mathrm{с}$ |
| Максимальная абсолютная разность МКР и аналитики на исходной сетке | $5.64545\cdot10^{-6}\ \mathrm{м}$ |
| Относительная разность к максимальному аналитическому перемещению | $0.0452\%$ |
| Наблюдаемый порядок на согласованных по времени сетках | $\approx2$ |
