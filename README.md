В репозитории реализована только первая задача из ДЗ: распространение волны сжатия от сферической полости в однородном изотропном линейно-упругом пространстве.

## Запуск

Требуются Python 3, NumPy и Matplotlib. Из корня репозитория выполните:

    python task1_wave.py --output-dir results

Скрипт строит сравнение численного и аналитического решения и сохраняет PNG/SVG-графики, CSV-профиль с абсолютной погрешностью и текстовую диагностику в каталоге results/.
